This is a repo of which the purpose is to automate shsh blob saving. This repo saves Baseband, AP and cryptex1. If you are wondering how this works, I have a job at https://cron-job.org which then starts the workflow every 30 minutes. Once the workflow runs, it will look into a private repo and see which shsh blobs are saved there, then it will query Apple´s TSS server for blobs for every build manifest from every ipsw that has ever existed for the iPhone 11 Pro. If TSS refuses, the workflows contiues. If TSS signs the ipsw the workflow will save a blob unless if it is already archived. It will then push these blobs into my pivate repo so that they will get archived. All sensitive values like APNONCE, BBSNUM (baseband serial number), BLOBS_REPO_TOKEN, CRYPTEX_NONCE, CRYPTEX_SEED, DISCORD_WEBHOOK, ECID and the GENERATOR are all saved as a github secret. The discord webshook is used to ping me on Discord when new blobs are saved. This workflow would most likely also catch older firmwares being accidently resigned by Apple. If you would like to fork this and make your own implementation please go ahead, the workflow usees the arm64 tsschecker release (I recommend using the latest release) to save blobs and check the signing status.
